# Registration_form
## 📝 Registration Form with Real-Time Validation

A modern and responsive **Registration Form** built using **HTML5, CSS3, and Vanilla JavaScript**. This project demonstrates real-time form validation, dynamic DOM manipulation, and table management without using any external libraries or frameworks.

## ✨ Features

- ✅ Modern and responsive UI
- ✅ Real-time form validation
- ✅ Name field validation (cannot be empty)
- ✅ Email format validation
- ✅ Password validation (minimum 6 characters)
- ✅ Error messages displayed dynamically using `prepend()`
- ✅ Submit button remains disabled until all fields are valid
- ✅ Stores submitted data in a table
- ✅ Remove button for deleting individual records
- ✅ Form automatically resets after successful submission
- ✅ Built using pure JavaScript (No frameworks)

## 📋 Validation Rules

### Name

- Cannot be empty

### Email

- Must be in a valid email format
- Example:
  - `example@gmail.com`

### Password

- Minimum length of **6 characters**

---

## 📊 Table Features

After a successful submission:

- User information is added to the table.
- Each row includes:
  - Name
  - Email
  - Password
  - Remove button
- Clicking **Remove** deletes that row instantly.
